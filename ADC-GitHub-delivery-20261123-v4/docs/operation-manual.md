# 系统功能与使用说明

## 岗位

| 岗位 | 功能 |
| --- | --- |
| 患者小程序 | 注册登录、本人资料、预约需求、改约/取消申请、预约及就诊详情查询 |
| 前台接待 | 患者档案、申请核验、预约办理、到诊和未到诊登记 |
| 接诊牙医 | 本人接诊安排、健康资料、沟通同意、实际诊疗及临床费用核实 |
| 收费人员 | 账单生成、项目明细、费用疑问、版本确认和模拟结算 |
| 采购人员 | 采购需求、供货情况和验收入库 |
| 诊所负责人 | 库存预警、实际耗用、经营异常补正、排班草案与生效 |
| 总部运营 | 季度统计、异常一致性检查、季度核算和报告导出 |
| 财务人员 | 读取核算版本并进行财务复核 |

## 预约到诊与诊疗

1. 患者选择门诊、医生、日期、项目及可选时间，明确确认后提交需求。
2. 前台核实身份及选择信息，再办理正式预约。需求提交不等于预约成功。
3. 到诊后前台登记，系统关联预约与本次就诊。预约日期与实际登记日期可能不同。
4. 医生输入预约编号查找本人接诊记录，核对“预约→就诊”和患者信息，点击使用。也可按登记日期查询。
5. 医生先查询健康资料，记录核实后的变更；沟通同意选择本次项目，可以包含多项。
6. 实际诊疗按项目记录实施情况、数量、患者可见的问题说明与后续注意事项。未实施项目不计费。

患者编号标识患者档案，预约编号标识一次预约，就诊编号标识一次接诊；不得混用。查找失败时核对岗位和预约号，不通过猜测编号访问其他患者。

## 账单与结算

收费工作台按状态查询账单，可选择全部。待出账就诊需要显式生成账单。详情展示项目、数量、单价、小计和总额；核对当前账单版本及申请人确认后进行模拟结算。模拟结算不会实际扣款。

费用疑问按类型登记；涉及临床项目或数量由原接诊医生核实，收费人员据结果处理账单版本，再取得本版确认。旧版本记录保留，不使用旧确认支付新版账单。

## 库存与季度经营

采购需求→供货记录→验收入库→库存查询。实际耗用填写数量、实际发生时间并确认成本依据后保存，系统显示扣减结果。金额与数量按输入框提示填写。

季度统计按季度和诊所形成快照。异常由诊所负责人补正、运营检查后重新统计。运营完成核算，财务对指定版本复核；通过后可导出可读报告并打印PDF。新业务不会自动改写旧统计或核算版本。

## 界面与异常提示

员工网页顶部显示当前岗位，左侧显示该岗位可用菜单。切换岗位使用右上角入口。小程序的我的预约和就诊记录分别展示预约进度、医生说明、项目及账单表格。

网络中断或显示结果待核对时，先查询原回执或重新读取结果，不重复创建业务请求。登录失效时重新登录；不要将密码、真实个人信息或令牌写入公共仓库。


## 季度历史记录与核算办理

总部运营按年份、季度及诊所选择查询服务器保存的统计快照和核算记录。单店与双店范围精确区分，重新登录后仍可查找。选择快照查看冻结金额和牙医业绩，再点击使用此快照新建核算；编号和范围自动带入。已有核算从列表查看，可切换已有历史版本，财务复核后导出同版本报告。财务从本岗位列表选择待复核记录，核对依据后显式复核；已复核状态可查看。查看记录不自动保存新核算。

费用来源为显式版本化合成清单，缺少某季度/诊所来源时保留待核实，明确无费用才计零。课程范围为81001、81002，总部及财务可处理授权范围，诊所负责人仍只处理本店。
