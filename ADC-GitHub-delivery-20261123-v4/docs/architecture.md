# 系统架构

系统由原生微信小程序、Vue员工网页、Spring Boot模块化单体和PostgreSQL组成。患者提交需求并查询本人信息，员工按岗位办理业务。

后端按照患者/预约、排班、诊疗、收费、库存和季度经营等职责组织模块。身份、岗位/诊所范围、参数校验、事务和审计在服务端处理。账单、临床记录与统计核算使用相应版本，页面不会覆盖已保存的历史版本。

数据库脚本保留在源码资源目录。数据库连接、账号密码和运行资料通过外部配置提供；公共仓库只保存模板和合成测试资料。课程支付使用模拟交易。

接口合同位于specs/*/contracts。医生按预约编号查找仍返回原患者和就诊编号，后续临床接口继续以就诊关联处理，不改变编号含义。
